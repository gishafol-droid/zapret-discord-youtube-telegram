## 🌐 О проекте

**NEXUS** — проект, посвящённый доступности популярных интернет-платформ.

Основная цель — предоставить пользователям Windows удобный инструмент для работы с сетевыми ограничениями и доступа к привычным сервисам.

### 🚀 Поддерживаемые сервисы

| Сервис | Назначение |
|---|---|
| Discord | Общение и голосовые каналы |
| YouTube | Видеоконтент |
| Telegram | Мессенджер и каналы |

## 💻 Совместимость

- Windows 10
- Windows 11
- Архитектура x64

## 📦 Возможности

- Удобная организация файлов проекта.
- Поддержка популярных интернет-сервисов.
- Простая структура репозитория.
- Обновления и улучшения проекта.

## 📥 Установка

1. Откройте раздел [Releases](../../releases).
2. Выберите актуальную версию, если она опубликована.
3. Скачайте архив проекта.
4. Распакуйте его.
5. Ознакомьтесь с инструкцией перед запуском.

## ⚠️ Важная информация

Проект предоставляется «как есть». Результат работы зависит от интернет-провайдера, сетевых настроек и актуальных ограничений.

Перед запуском проверяйте скачанные файлы антивирусом. Не запускайте неизвестные исполняемые файлы с повышенными правами.
